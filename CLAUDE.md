# Undaunted Normandy — веб-помощник соло-бота

Цель: веб-приложение, которое ведёт игрока по дереву решений простого
соло-бота для настольной игры Undaunted: Normandy (правила бота —
`bot_script.txt`). Игрок выбирает юнита, чья карта выпала, отвечает на
вопросы да/нет/выбор, где нужно — считает через встроенные калькуляторы
(ключевая точка, выбор цели атаки, квадрат миномёта), приложение
говорит, какое действие выполнить.

**Начинай работу с чтения `PLAN.md` и `TODO.md`** — там стратегия, факты
и текущий рабочий список. Не восстанавливай статус из памяти/истории
чата — файлы это источник истины. Неоднозначности правил и решения по
ним — в `OPEN_QUESTIONS.md`.

## Специфичные для проекта правила

(в дополнение к глобальному `~/.claude/CLAUDE.md`, который действует всегда)

- Стек: Vite + React + TypeScript, чистый фронтенд без бэкенда.
- Дерево решений бота хранится как JSON в `src/data/` (формат — см.
  `src/data/SCHEMA.md`).
- Настройки игрока (цель ИИ, тема оформления) — в localStorage браузера.
- Git инициализирован, репозиторий на GitHub пока не подключён — см.
  `HOSTING.md` для команд подключения/деплоя.
