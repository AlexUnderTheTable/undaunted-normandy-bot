# Undaunted Normandy — веб-бот сценариев

Цель: веб-приложение, которое ведёт игрока пошагово по заранее заданному
сценарию (скрипту) настольной игры Undaunted: Normandy — как гид,
показывающий текущий шаг и позволяющий двигаться дальше/назад.

**Начинай работу с чтения `PLAN.md` и `TODO.md`** — там стратегия, факты
и текущий рабочий список. Не восстанавливай статус из памяти/истории
чата — файлы это источник истины.

## Специфичные для проекта правила

(в дополнение к глобальному `~/.claude/CLAUDE.md`, который действует всегда)

- Стек: Vite + React + TypeScript, чистый фронтенд без бэкенда.
- Сценарии игры хранятся как JSON внутри проекта (см. `PLAN.md` про формат).
- Прогресс прохождения сценария — в localStorage браузера.
- Git пока не инициализирован — не предлагать commit/push, пока не попросят.
